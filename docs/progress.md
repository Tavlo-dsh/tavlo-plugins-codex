## 已知缺口与依赖

- **用量展示：** 权威数据位于 `tavloCodex` 投影及 `/codex usage`；宿主原有 token-meter 无法分离两个口径，标准 usage 已停止上报。插件底栏直接读取原生投影，显示 token、缓存、上下文与原生回合均速。未知旧线程恢复／分叉首通知前可能少计，标记 inferred；持有基线的正常恢复准确计增量。
- **Plan：** 命令、步骤和最终正文已接入；模式与权限独立，未完成草稿不能执行。独立图形面板按用户反馈撤下。
- **名称与 Goal：** 人工名称固定优先。Codex 原生 Goal 的跨回合、预算和重启已验证；目前与 DSH 自带 `ctx.goals`／`goal` 投影尚未桥接。用户已要求复用宿主目标入口和目标栏，新增 M3.6，先清理并提交当前生命周期修复，再实现桥接。
- **子代理：** 事件与每秒只读后代查询收敛状态，不为订阅恢复子线程；父边界等待真实终态，超时关闭进程。子代理内部逐 token 输出不在本次范围。
- **界面依赖：** Fast 和统计使用 DSH 已发布扩展位；四项独立工作面板已撤下，不再作为待办。
- **验证范围：** 已有真实 DSH headless 带认证文字回合，以及 Codex 0.169.0 的权限／生命周期验证。已撤下面板的浏览器验证仅作历史记录。其余真实图片／工具／审批／恢复／分叉的完整组合与旧 CLI 版本尚待验收。早期文字回合约 6 分 32 秒，原因未确定，不能把 RPC 应答超时当模型回合时限。
- **权限：** 支持宿主实际 sandbox／approval 及派生 custom；运行中变更通过中断和同线程接续应用，原生不支持直接修改活动回合的这两个字段。DSH Auto 依赖宿主执行链，仍明确拒绝；新实现需在现有 Host 重载插件后使用。
