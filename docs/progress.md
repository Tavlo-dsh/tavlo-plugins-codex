- **Plan：** 已实现 `/codex plan/default/execute/keep`，步骤与最终正文独立保存；图形确认按钮需统一 UI 接入。
- **名称与 Goal：** 名称同步已实现，人工名称固定优先，失败独立记录。Goal 已实现有界控制；原生无人干预连续运行未开放，真实跨回合验收仍待完成。
- **子代理：** 已有状态投影、命令列表／详情与活跃子代理控制；未强行订阅子线程，缺失事件可按需读历史。图形面板、真实并发事件订阅与重启生命周期待验收。
- **界面依赖：** 当前工作区未见 `tavlo-plugins-ui` 源码。M1.1 先核对 DSH 原有扩展点；开始界面实现前确定承载项目与接口。
- **验证范围：** 本机 `codex-cli 0.167.2` 原生控制协议和真实 DSH headless 带认证文字回合通过；完整图形操作、真实工具／图片／审批／恢复与旧 CLI 版本尚未验收。真实回合约 6 分 32 秒，原因未确定，不能把 RPC 应答超时当模型回合时限。
- **权限：** 支持宿主实际 sandbox／approval 及派生 custom；DSH Auto 依赖宿主执行链，原生工具无法按该链审查，明确拒绝该预设。
