# Codex 生命周期验证与界面调整

日期：2026-11-17。实现位于 0.2.1 之后的未发布工作区；不将前一版本的发布状态用于本次新增功能。

## 已完成

- 按用户反馈撤下输入框上方的 Plan／工具进度／Goal／子代理面板，保留 Fast 开关和统计底栏；Plan 和其他操作继续使用 `/codex` 命令。
- 工具进度：保留命令增量、MCP 消息、文件补丁和回合 diff 的持久投影；64 KiB 输出尾部、128 项工具和每工具 32 条消息。子线程 diff 不覆盖根线程 diff。
- Goal 生命周期：显式创建、预算、暂停、清除和继续一轮。回合结束、正常卸载暂停；异常重启重新读取目标及用量后暂停。目标已完成、受阻或受限时不被自动暂停改写，重复 resume 被拒绝。
- DSH Goal 桥接：复用宿主既有目标入口与目标栏；宿主准入续轮，原生每轮结束回传完成／暂停／受阻。运行中编辑、暂停或清除中断旧回合，按版本隔离旧结果，不增加独立面板。
- 子代理生命周期：状态、关系和结果、补充消息与停止；事件加每秒只读后代查询恢复遗漏信息。中断后等待终态，覆盖启动、迟到事件、进程丢失及恢复；不恢复子线程以取得订阅。

## 真实原生生命周期

`pnpm test:local:lifecycle` 使用本机 Codex 0.169.0、临时 `CODEX_HOME`、loopback Responses 服务和测试密钥。没有使用用户配置或付费模型。

- 同一 Goal 显式执行两轮；已用 token 从 130 增至 260，预算 10000 保留，两轮均在边界暂停。
- 目标再次 active 后直接结束原生进程；重连后读取原生目标并暂停，预算与用量保留，没有提交额外用户回合。
- 正常退出、重建 CodexSession 后仍为同一线程，原生预算和用量一致；clear 清除原生目标。
- 原生 `multi_agent_v1.spawn_agent` 生成两个并发子代理；父任务结束后两个子代理均确认 interrupted，活动 turn id 清空。
- 原生后代查询能找到两个子代理；重启后仍保留终态，没有对子线程调用 resume。
- 故意结束进程时，尚未完成的可选模型目录查询可能报告 connection closed；该告警属于测试注入的断线，正常生命周期阶段没有其他告警。

## 真实 DSH 目标桥接

`scripts/verify-host-goal.mjs` 在全新临时 DSH Web profile 安装本次候选包，使用 DSH 0.2.2-rc.1、Codex 0.169.0、独立 `CODEX_HOME` 和 loopback Responses 模型。目标通过真实 `ctx.goals` 创建和操作，由真实 `goal-round-driver` 调度。

| 场景 | 结果 |
| --- | --- |
| 自动续轮与完成 | 精确准入第 1、2 轮；原生 `update_goal` 返回完成，既有目标栏读取的 `goal` 投影为 complete，原生 Goal 同为 complete，无第 3 轮 |
| 运行中暂停与清除 | 宿主暂停后当前回合停止、原生 Goal paused；清除后宿主目标、原生目标及绑定均为空 |
| 原生受阻 | 原生 `update_goal` 报告 blocked，宿主停在第 1 轮，原因为 `codex-blocked` |
| 模型执行失败 | loopback 返回 HTTP 500，宿主停在第 1 轮，保留具体失败，原因为 `codex-turn-failed` |

结果保存在工作区 `.refs/verification/codex-host-goal-result.json`。共 6 次本地模型请求、0 次付费调用；验证使用真实宿主服务和目标栏投影，没有浏览器点击步骤。脚本通过内容 hash 命名临时 tarball，避免同版本候选包的安装缓存；构建、打包与运行方法见 [README](../README.md#开发)。

## 边界

独立 `/codex goal` 保持显式继续一轮；DSH 目标模式由宿主按轮数上限自动续轮，插件不另设调度器。DSH 轮数与原生 token 预算分开，增加轮数或恢复目标不能解除原生用量限制。子代理状态通过事件和只读查询收敛，正常活动期间查询间隔一秒；不承诺逐 token 的子代理内部输出。旧 CLI 若缺少后代查询能力会显示错误，边界核对失败时停止进程。停止不撤销已经发生的外部副作用。

本轮未重启用户正在使用的 Host。当前源码链接需要重新加载 Codex 插件并刷新页面才能使用新版客户端与 Host；本轮未发布新 npm 版本。M6.2 既有目标栏浏览器交互、宿主目标重启／分叉及其余图片等完整组合，M6.3 更广泛故障矩阵保持开放。
